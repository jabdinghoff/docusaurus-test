Du musst nichts installieren. Die Dokumentation wird im Browser mit
[Pages CMS](https://app.pagescms.org) bearbeitet, und die Website aktualisiert
sich ein bis zwei Minuten nach dem Speichern von selbst.

## Zugriff erhalten

Bitte die verantwortliche Person, dich einzuladen. Du bekommst eine E-Mail von
Pages CMS; klicke auf den Link darin, um dich anzumelden. Ein GitHub-Konto ist
nicht nötig.

## Eine Seite bearbeiten

1. Öffne [app.pagescms.org](https://app.pagescms.org) und wähle dieses Projekt.
2. Klicke in der Seitenleiste auf **Pages (Deutsch)** und wähle die Seite, die du ändern möchtest.
3. Bearbeite den Text wie in einer Textverarbeitung. Tippe `/` in einer leeren Zeile für Überschriften, Listen, Tabellen und Bilder.
4. Speichern. Fertig — die Website wird automatisch neu erstellt.

Eine deutsche Seite muss genauso heißen wie die englische Seite, die sie
übersetzt. Neue Seiten legst du deshalb zuerst auf Englisch an. Seiten ohne
deutsche Übersetzung erscheinen auf Englisch.

## Auf eine andere Seite verlinken

Markiere den Text, klicke in der kleinen Werkzeugleiste auf die Link-Schaltfläche
und gib den Dateinamen der anderen Seite ein, z. B. `editing-these-docs.md`. Um
zu einem Abschnitt zu springen, hänge die Überschrift in Kleinbuchstaben mit
Bindestrichen an, z. B. `editing-these-docs.md#zugriff-erhalten`.

## Bilder

Nutze `/` → **Image** im Editor oder lade Dateien zuerst unter **Images** in der
Seitenleiste hoch und wähle sie dort aus.

![](/img/logo.svg)

## Was du vermeiden solltest

- Schreibe keine große „Überschrift 1“ an den Anfang einer Seite; das Feld **Title** wird bereits zur Seitenüberschrift. Beginne mit „Überschrift 2“ oder kleiner.
- Manche Seiten enthalten Zeilen wie `:::note` oder `:::`. Das sind besondere Anweisungen für die Website — lass sie unverändert und bearbeite nur den Text dazwischen.
- Der Editor entfernt HTML-Kommentare (`<!-- ... -->`) beim Speichern.

:::tip

Du möchtest einen farbigen Kasten wie diesen? Schreibe `:::tip` in eine eigene
Zeile, darunter deinen Text und `:::` in die Zeile danach. `note`, `info`,
`warning` und `danger` funktionieren auch.

:::
